# 🚗 Vehicle Manager

A dynamic vehicle management system built with vanilla HTML, CSS & JavaScript (DHTML).

## Features

- Add vehicles with type, manufacturer, color picker and price
- Persistent storage using `localStorage`
- Dynamic table with live stats (total count & value)
- Remove individual vehicles or clear all
- Form validation
- Responsive glass-morphism dark UI

## Tech Stack

- **HTML5** — Semantic markup, RTL Hebrew layout
- **CSS3** — Glass-morphism, CSS Grid, custom properties, animations
- **JavaScript (ES5)** — DOM manipulation, localStorage, dynamic table rendering

## Run

Open `index.html` in any modern browser — no build step required.
